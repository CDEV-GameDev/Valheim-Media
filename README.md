# Valheim-Media

Images for the pages of the CDEV Valheim mods. Thunderstore does not host screenshots itself — a mod page is
just its README — so the pictures live here and the pages link to them.

**This repository holds media only**: screenshots, banners, gifs and video of the mods. No mod code, no
builds, no configs — those live in their own place.

## Layout

One folder per plugin, named exactly like the plugin:

```
CDEV.EquipmentSlots/
CDEV.PortalPins/
CDEV.HoverInfo/
CDEV.RebindFavoriteKey/
```

## Linking a picture

Use the raw URL (case-sensitive):

```markdown
![The equipment panel](https://raw.githubusercontent.com/CDEV-GameDev/Valheim-Media/main/CDEV.EquipmentSlots/panel.jpg)
```

Screenshots are taken in Valheim (Iron Gate AB) and resized to 1600 px wide before they are committed.

# Valheim-Media — по-русски

Картинки для страниц модов CDEV к Valheim. Thunderstore не хранит скриншоты у себя — страница мода это его
README, — поэтому изображения лежат здесь, а страницы ссылаются на них.

**В репозитории только медиа**: скриншоты, баннеры, гифки и видео модов. Ни кода, ни сборок, ни конфигов.

Структура — по папке на плагин, имя папки совпадает с именем плагина (`CDEV.EquipmentSlots/` и так далее).
Ссылка на картинку берётся в виде `raw.githubusercontent.com/CDEV-GameDev/Valheim-Media/main/<плагин>/<файл>`;
регистр в пути важен. Скриншоты сняты в Valheim (Iron Gate AB) и перед коммитом уменьшены до ширины 1600 px.
